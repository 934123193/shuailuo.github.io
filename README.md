# Shuai Luo Academic Homepage

This repository contains the personal academic homepage of Shuai Luo.

## Profile

Shuai Luo works at the intersection of forensic medicine, medical imaging, and artificial intelligence, with research interests in:

- Forensic age estimation
- Multidetector CT and bone mineral density analysis
- Fetal brain MRI and gestational age estimation
- Deep learning semantic segmentation for medical image quantification
- Large language model APIs for academic research workflows

## Local Preview

```powershell
npm install --legacy-peer-deps
npm run dev
```

Open <http://localhost:3000>.

## Build

```powershell
npm run build
```

The static site is exported to `out/`.

## Deploy

Push the repository to:

```text
https://github.com/934123193/shuailuo.github.io
```

Then enable GitHub Pages with GitHub Actions in the repository settings.
